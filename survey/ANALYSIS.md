# Google Forms Survey Analysis

## Overview

This project contains the analysis of survey responses collected through Google Forms for the team project.

The goal of the analysis is to understand users' experience and preferences when choosing movies together, identify key insights, and support product decisions with data.

## Work Completed

- Set up the local environment for survey analysis.
- Adapted the Google Forms analysis notebook for execution in Visual Studio Code.
- Loaded and processed survey data using Python.
- Performed exploratory data analysis and visualized survey results.
- Prepared a consolidated dataset for further analysis in Tableau.
- Exported the processed data to CSV format.

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- Tableau

## Files

- `survey_analysis.ipynb` — notebook containing the survey analysis workflow.
- `outputs/tableau_all_data.csv` — processed dataset prepared for Tableau.
- `../data/survey.xlsx` — source survey data.
